# Problem Set Solutions

This repository contains solutions to a set of Python programming problems. Each problem is implemented in a separate file (problem 1.py, problem 2.py, etc.).

## Problems Overview

1. **Second Largest Distinct Element**
   - Finds the second largest distinct integer in an array.
2. **Palindrome Checker**
   - Checks if a string is a palindrome, ignoring case and non-alphanumeric characters.
3. **Most Frequent Word**
   - Returns the most frequent word in a string, case-insensitive, with ties broken alphabetically.
4. **Unique Pairs with Target Sum**
   - Finds all unique pairs of integers in an array that sum to a given target.

## How to Run

1. Make sure you have Python installed (version 3.x).
2. Open a terminal in the folder containing the problem files.
3. Run a problem file using:
   ```
   python "problem 1.py"
   ```
   Replace the filename as needed for each problem.

## Notes
- Each file contains a function for the problem and can be tested by adding your own test cases at the bottom of the file.
- No external libraries are required (only standard Python libraries are used).
- Solutions handle edge cases as described in each problem statement.
